# AI workflow note

I used an AI coding assistant in VS Code to scaffold Next.js, draft the API/data-layer shape, and iterate on the editor UI. AI accelerated project setup and helped focus on the highest-value assignment paths.

I rejected the default starter UI and did not add broad Google Docs features, real-time collaboration, or full authentication under the timebox. I corrected generated data-layer code and a React lint issue rather than accepting output blindly. Correctness was checked with the production build, ESLint, parameterized SQL, explicit API errors, and a manual create/edit/save/reopen/import/share flow.
